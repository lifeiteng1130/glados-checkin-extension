# GLaDOS 自动签到浏览器扩展

基于 Manifest V3 的本地浏览器扩展，支持固定时间或当天随机时间签到。无需填写账号密码或手动复制 Cookie，使用当前浏览器已有的 GLaDOS 登录会话。当前版本：`2.1.0`。

## 功能

- 固定时间签到，默认每天 `09:00`，使用电脑本地时间。
- 当天随机时间签到，默认范围 `08:00–10:00`；每日抽取一次并保存，修改设置后重新生成。
- 接口返回失败后按设置间隔重试，默认 `120` 分钟；重试不跨当天。
- 手动签到、打开签到页面、查看签到结果和最近执行时间。
- 在扩展弹窗内展开设置，无需单独打开设置页。

## 安装

1. 下载本仓库 ZIP 并解压，或使用 `git clone` 获取源码。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的项目文件夹。
5. 在同一浏览器用户配置中打开 `https://www.glados.one/console/checkin`，正常登录自己的账号。
6. 点击扩展图标，先尝试一次“立即签到”，确认登录状态和返回结果。

本项目未发布到扩展商店；Edge 等 Chromium 浏览器的实际兼容性需自行验证。

## 设置与使用

点击“签到设置”，选择固定时间或随机时间范围，设置失败重试间隔后保存。随机范围仅支持当天，结束时间必须晚于开始时间，不能跨午夜。

签到时扩展会短暂打开后台标签页，在网页中发送签到请求，结束后关闭该标签页。电脑和浏览器需要处于可运行状态；电脑关机或浏览器完全退出时无法按计划执行。浏览器启动后会重建当天计划，已错过的计划可能立即补执行。

网页登录失效时，请通过“打开签到页面”重新登录，再手动签到。

## 隐私与权限

源码不包含个人邮箱、账号密码、Cookie 或登录 Token。扩展不申请 `cookies` 权限，不直接读取、导出或保存 Cookie；网页请求通过 `credentials: include` 使用浏览器管理的登录会话。

设置、当天计划和签到状态保存在浏览器扩展的 `chrome.storage.local` 中。插件没有自建服务器或遥测上传逻辑；签到请求发送到 GLaDOS。

| 权限 | 用途 |
| --- | --- |
| `alarms` | 安排每日签到、重试和次日计划重建 |
| `storage` | 保存设置、计划和结果 |
| `tabs` | 打开和关闭签到标签页 |
| `scripting` | 在签到网页中执行接口请求 |
| `notifications` | 当前声明但尚未使用 |
| `https://www.glados.one/*` | 仅允许访问指定 GLaDOS 域名 |

只分享源码文件夹不会包含浏览器登录数据。请勿附带浏览器用户数据目录、Cookie 导出文件或扩展存储备份。

## 已知限制

- 页面加载超时、网络请求抛异常等情况目前只记录失败，不会自动安排重试；可手动重试。
- 关闭自动签到后，手动签到若收到失败响应仍可能创建重试任务。
- “下次执行”在首次等待时可能为空；成功后显示的是次日 `00:05` 的计划重建时间，并非实际签到时间。
- 浏览器后台调度可能延迟，无法保证精确到指定分钟；网站域名、接口或验证机制变化后可能需要更新。
- 当前只使用同一浏览器配置中的登录账号，不提供多账号管理。

## 开发与验证

无需构建或安装第三方依赖。使用支持 `node:test` 的 Node.js 运行：

```sh
npm test
node --check background.js
node --check popup.js
```

若运行环境禁止测试器创建子进程，可使用支持该参数的 Node.js：

```sh
node --test --test-isolation=none tests/extension.test.mjs
```

现有测试覆盖权限配置、弹窗设置结构和时间辅助函数，尚未覆盖完整后台调度及真实签到。

## 项目结构

```text
manifest.json          扩展配置和权限
background.js          后台调度、签到与消息处理
popup.html / popup.css 弹窗界面
popup.js               弹窗交互
src/checkin-core.js    时间、设置校验和响应分类
tests/                本地自动化测试
```

本项目为非官方工具，与 GLaDOS 无隶属关系。请遵守所使用服务的规则。
